
# MyToDo - Laravel + React (Inertia + Vite)

Description

MyToDo is a web-based task management application built with Laravel on the backend and React (Inertia + Vite) on the frontend.
It helps users create, manage, and track daily tasks through an interactive dashboard.
## Features

- Add, edit, and delete tasks
- Mark tasks as completed or pending
- Dashboard summary: total tasks, completed tasks, tasks due today, and progress percentage
- Filter tasks by status and search by keywords
- Task categories and priorities (High, Medium, Low)
- Task detail page with full information
## Tech Stack

**Backend:** Laravel

**Frontend:** React + Inertia.js + Vite

**UI Components:** TailwindCSS, Lucide Icons, Radix UI

**State Management & Interactivity:** React Hooks

**Database:** MySQL (via Eloquent ORM)
## Installation

Clone the repository:

```bash
git clone https://github.com/ZamiFaiz24/My_ToDo---Laravel-Inertia-React.git

cd My_ToDo---Laravel-Inertia-React

```

Install Laravel dependencies:

```bash
composer install

```

Install frontend dependencies:

```bash
npm install
npm run dev

```
